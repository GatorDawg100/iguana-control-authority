# Iguana Control Authority — Official Modern Website

A high-converting, responsive, SEO-optimized website built for **Iguana Control Authority** (founded by **Avi Ezra**) serving **Palm Beach, Broward, Miami-Dade, and Monroe Counties** in South Florida.

---

## 🌟 Key Features

### 1. High-Converting Design & Mobile Responsiveness
- **South Florida Aesthetic**: Emerald greens (`#064e3b`, `#10b981`), warm gold badges (`#fbbf24`), and slate dark mode.
- **Mobile-First Experience**: Sticky bottom call & quote bar (`(305) 922-4210` & `Free Estimate`), tap-to-call, tap-to-text with photo attachment prompts.
- **Fast Lead Capture**: Multi-step Free On-Site Inspection form with confetti celebration and analytics event firing.

### 2. Interactive Property Assessment & Cost Guidance Calculator
- Lets property owners select their property type (Waterfront Seawall, Inland Home, HOA / Community, Commercial / Marina), primary affected area, and infestation severity.
- Instantly generates a customized treatment & defense protocol with scope of work and one-click booking.

### 3. Real Field Work Gallery
- Showcases authentic, real-world photos from Avi Ezra's jobs:
  - Branded RAM service truck with logo and direct phone number
  - Waterfront canal & seawall captures along luxury yacht docks
  - Humane live cage traps positioned in garden corridors
  - Precision FWC-compliant removal equipment
  - Lawn & patio infestation remediation

### 4. Comprehensive Service Pages & Education
- **Waterfront Seawall & Dock Defense**: Prevents catastrophic sinkholes, soil washout, and cracked seawall caps ($10k-$40k savings).
- **Humane Live Trapping & Eradication**: FWC-compliant multi-catch traps and ethical protocols.
- **Tree Wrapping & Anti-Climb Barriers**: Slick aluminum sheet collars to prevent roof and pool enclosure climbing.
- **Commercial & HOA Programs**: Recurring patrol, resident education, and community-wide sweeps.
- **Burrow & Egg Nest Destruction**: Neutralizing breeding chambers to prevent 30-70 new hatchlings per clutch.
- **Pool Deck Sanitization**: Eradicating Salmonella contamination from outdoor living spaces.

### 5. Local South Florida SEO (Targeted Cities & Counties)
- **Palm Beach County**: Boca Raton (HQ at 950 Peninsula Corp), Delray Beach, Palm Beach, Highland Beach, Boynton Beach, Wellington, Jupiter.
- **Broward County**: Fort Lauderdale, Pompano Beach, Coral Springs, Lighthouse Point, Hollywood, Parkland, Weston.
- **Miami-Dade County**: Miami, Coral Gables, Key Biscayne, Aventura, Coconut Grove, Pinecrest, Sunny Isles Beach.
- **Monroe County**: Key Largo, Islamorada, Marathon, Tavernier, Upper Florida Keys.

### 6. Technical SEO & Schema.org Structured Data
- Complete Schema.org **`LocalBusiness`** / **`PestControl`** JSON-LD structured data with geo coordinates, opening hours, pricing, telephone, and service catalog.
- Schema.org **`FAQPage`** markup for Google rich snippets.
- Open Graph and Twitter Card tags.
- `robots.txt` and `sitemap.xml` included in `public/`.

### 7. Built-in Analytics & Event Tracking
- Integrated Google Analytics 4 (GA4) tracker with Google Tag Manager `dataLayer` support.
- Pre-configured event tracking for:
  - `phone_call_click` (tracks which section or button drove the call)
  - `sms_click` (tracks text message photo inquiries)
  - `estimate_form_submitted` (captures service type & county)
  - `assessment_calculator_complete` (captures property type & severity)
  - `service_view`
- Privacy-compliant Cookie Consent banner with persistent local storage.

## 🛠️ Development & Deployment

### Quick Commands

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle (outputs to /dist)
npm run build

# Preview production build locally
npm run preview
```

### Hosting & Deployment Options
The `/dist` directory contains a static production bundle that can be deployed to:
- **GoDaddy Web Hosting** (upload `/dist` contents via cPanel / FTP)
- **Vercel / Netlify / Cloudflare Pages** (connect GitHub repository, build command `npm run build`, output directory `dist`)
- **AWS S3 / Firebase Hosting / GitHub Pages**
